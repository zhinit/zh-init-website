# Web Design Process

The end-to-end workflow for designing a website. Visitors make judgments in
roughly 50 milliseconds, with 94% of first impressions based on design alone
(source: clay-web-design-guide-2026.md).

## Eight steps

1. **Define purpose** — what the site should accomplish. Without this, design
   decisions have no anchor.

2. **Choose platform** — CMS, e-commerce, static site generator, or headless
   architecture. See [[portfolio-design]] for platform trade-offs.

3. **Map structure** — information architecture and navigation. Content
   organization should follow user intent, not internal org structure.
   Navigation under 5-7 items with descriptive labels (source:
   clay-web-design-guide-2026.md).

4. **Wireframe → Mockup → Prototype** — progression from structural sketches
   to visual mockups to interactive testing. Each stage adds fidelity.

5. **Build and code** — HTML, CSS, JavaScript implementation. Component-based
   architecture with reusable UI elements ensures consistency. Design tokens
   (named variables) allow global updates (source:
   clay-web-design-guide-2026.md).

6. **Optimize for SEO** — semantic HTML structure and content strategy. WCAG
   accessibility improvements also benefit SEO (source:
   clay-web-design-guide-2026.md).

7. **Test thoroughly** — cross-browser, cross-device, and usability validation.
   Use Lighthouse and Axe for accessibility auditing (source:
   clay-web-design-guide-2026.md).

8. **Launch and iterate** — continuous improvement using analytics and A/B
   testing.

(source: clay-web-design-guide-2026.md)

## Performance standards

Page speed directly impacts conversions: "a one-second delay cuts conversions
by 7%" (source: clay-web-design-guide-2026.md).

Optimization techniques:
- Image compression using WebP and AVIF formats
- Lazy-loading below-the-fold content
- CSS/JavaScript minification
- Content Delivery Networks (CDNs)
- Browser caching

## Conversion optimization

- Specific, action-oriented CTA copy
- Single-goal landing pages with distractions removed
- Social proof positioned near decision points
- Align layout with F-pattern and Z-pattern reading behavior

(source: clay-web-design-guide-2026.md)

## Visual content

Photography should be high-resolution and purposeful. Custom illustration
makes abstract concepts tangible. Animation should guide or explain, not
impress decoratively. Scroll-triggered animations appear in 52% of modern
designs and improve interaction rates by 27% (source:
clay-web-design-guide-2026.md).

## Common mistakes

- Cluttered layouts without [[visual-hierarchy]]
- Missing or unclear CTAs
- Slow page loads
- Inconsistent [[typography]] and [[whitespace]]
- Mobile-unfriendly experiences
- Images lacking alt text
- Navigation misaligned with user mental models

(source: clay-web-design-guide-2026.md)

## Key principle

"Good web design disappears" — users find what they need intuitively,
understand required actions, and instinctively trust the brand. Design serves
usability above aesthetics (source: clay-web-design-guide-2026.md).
