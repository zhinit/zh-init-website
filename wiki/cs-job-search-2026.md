# CS Job Search 2026

Context for the entry-level software engineering job market as of 2026. A
portfolio website is one piece of a broader strategy; this page covers the
rest.

## Market reality

Record numbers of CS graduates are colliding with cooling demand for
entry-level software engineers (source: sjonany-cs-job-hunt-2026.md). Junior
developers should expect 100+ applications before landing a role. This is the
environment in which portfolio decisions are being made — high competition
means differentiation matters more than it did in 2019-2021.

## Prerequisites before applying

Three fundamentals, per the Jonany playbook (source:
sjonany-cs-job-hunt-2026.md):

1. **Data structures knowledge** — priority queues, hashing, Big-O analysis
   from a formal course
2. **At least one portfolio project** — with GitHub documentation and design
   rationale. See [[portfolio-projects]].
3. **Professional presence** — LinkedIn, resume, ideally a personal website.
   See [[portfolio-website]].

## Daily practice

Two-pronged daily commitment (source: sjonany-cs-job-hunt-2026.md):
- 30 minutes applying to positions
- 30 minutes skill development

## Job search tactics

From the Jonany playbook and HN accounts (source:
sjonany-cs-job-hunt-2026.md, hn-personal-website-helped-get-hired.md):

- **Personalize resumes** for each role
- **Cold email hiring managers directly** — not just apply through portals
- **Leverage existing networks** — referrals remain the highest-conversion
  channel
- **Expand to adjacent roles** — QA, DevOps, support engineering, technical
  writing are viable entry points if SWE applications stall
- **Attend meetups** — one HN commenter got hired after connecting at a local
  JavaScript meetup (source: hn-personal-website-helped-get-hired.md)

## Technical skills employers expect

Even from entry-level hires, often absent from university curricula (source:
sjonany-cs-job-hunt-2026.md):

- Cloud infrastructure tools (Docker, Terraform, AWS services)
- LLM APIs
- System design fundamentals

## The resume vs. portfolio debate

The Kettmann survey found that most developers spend far more time on
portfolio websites than resumes, creating an opportunity to stand out through
quality resume work (source: kettmann-dont-waste-time-portfolio-website.md).
A strong resume is a prerequisite; a portfolio website is a supplement.

## GitHub as portfolio

A well-maintained GitHub profile has a 40% increase in interview callbacks
(source: hakia-developer-portfolio-guide-2026.md). Optimization checklist:

1. Profile README with intro, current focus, tech stack
2. Pin 6 best repositories across different stacks
3. Compelling repo descriptions (not "Todo app")
4. Consistent commit history showing active development
5. Meaningful commit messages
6. Repository topics for discoverability

## Interview preparation

Practice mock interviews with peers and AI tools. Clarify interview format
beforehand, including whether AI tools are permitted during technical rounds
(source: sjonany-cs-job-hunt-2026.md).
